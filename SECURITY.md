# Kebijakan keamanan

secret-guard adalah proyek belajar dan bukan pengganti alat yang matang.

- **Cara melewati pemindai** (rahasia yang lolos): buka issue dengan contoh **palsu**.
  Jangan pernah menempel rahasia sungguhan.
- **Kerentanan di kode**: laporkan lewat tab Security di GitHub ("Report a vulnerability")
  bila tersedia. Kalau tidak, buka issue tanpa detail eksploit.
- Kalau rahasia sungguhanmu pernah ter-push, cabut dan ganti sekarang. Menghapusnya
  dari repo tidak cukup.
